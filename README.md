# Instagram-user-analytics

OVERVIEW

This project focuses on analyzing Instagram user data to extract meaningful insights that support marketing strategies,
platform optimization, and investor decision-making. Using SQL, we explored a relational database of Instagram users 
and activities to address key business questions.

OBJECTIVES

*Identify and segment loyal and highly active users

*Encourage inactive users to engage more with the platform

*Analyze user activity to declare contest winners

*Research popular hashtags and trends to guide content creation

*Determine the best day to launch ad campaigns

*Assess user engagement levels and post activity

*Detect bots and fake accounts based on behavior patterns

TOOLS & TECHNOLOGIES

*SQL (MySQL / PostgreSQL) – for querying and data analysis

*DBMS – structured relational database provided

IMPACT

*The insights derived from this project help:

*Support targeted marketing campaigns

*Improve user engagement and platform experience

*Aid leadership in data-driven decisions

*Offer performance metrics for investor evaluation

KEY HIGHLIGHTS

*Wrote optimized SQL queries to handle large datasets efficiently

*Applied analytical thinking to solve real-world business problems

*Delivered actionable recommendations based on data trends
